# 중학교 2학년 반편성 프로그램 (Google Apps Script)

구글 스프레드시트에 1학년 학생명단을 입력하면, 조건에 맞춰 2학년 반을 자동으로 편성하고
화면에서 끌어다 놓기로 조정한 뒤 시트에 결과를 저장하는 프로그램입니다.

## 파일
| 파일 | 역할 |
|---|---|
| `Code.gs` | 시트 읽기/쓰기, 메뉴, 웹앱 진입점 |
| `Index.html` | 반편성 화면 (자동 편성 알고리즘 + 수동 조정) |

## 설치 방법
1. 구글 스프레드시트를 새로 만듭니다.
2. **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 `Code.gs` 내용을 지우고 이 폴더의 `Code.gs`를 붙여 넣습니다.
4. **파일 추가(+) → HTML**을 눌러 이름을 `Index`로 만들고 `Index.html` 내용을 붙여 넣습니다.
5. 저장 후 스프레드시트를 새로고침하면 상단에 **🏫 반편성** 메뉴가 생깁니다.
   (처음 실행할 때 권한 승인 창이 뜨면 허용합니다.)

### 사용 방법 두 가지
- **스프레드시트 안에서**: 메뉴 `🏫 반편성 → 반편성 프로그램 열기`
- **웹앱(전체 화면)**: Apps Script 편집기에서 `배포 → 새 배포 → 웹 앱`
  (실행 사용자: 나, 액세스: 나만 또는 학교 도메인) → 나온 URL로 접속

## 학생명단 시트 양식 (`학생명단`)
메뉴 `학생명단 양식 만들기`로 머리글을 만들거나 `예시 데이터 채우기`로 연습용 150명을 넣을 수 있습니다.

| 학번 | 이름 | 성별 | 성적 | 이전반 | 특수 | 생활지도 | 분리학생 | 동반학생 | 고정반 | 비고 |
|---|---|---|---|---|---|---|---|---|---|---|
| 10101 | 김민준 | 남 | 85.5 | 1 | | Y | 10215,이서연 | | | |

- **성별**: 남/여
- **성적**: 점수(숫자). 비어 있으면 전체 평균으로 계산
- **이전반**: 1학년 반. 비우면 5자리 학번의 2~3번째 자리에서 자동 추출 (10312 → 3반)
- **특수 / 생활지도**: `Y`(또는 O, 1) 표시 → 각 반에 고르게 분산
- **분리학생**: 같은 반이 되면 안 되는 학생 (학번 또는 이름, 쉼표 구분). 한쪽에만 적어도 양쪽에 적용
- **동반학생**: 반드시 같은 반이어야 하는 학생
- **고정반**: 반드시 배정할 2학년 반 번호

## 편성 방식
1. 고정반 학생을 먼저 배치합니다.
2. 남/여 각각 성적순으로 **S자(지그재그) 배정**을 해 기본 균형을 맞춥니다.
3. **담금질(Simulated Annealing) 최적화**로 학생 맞교환·이동을 수십만 번 시도하며 아래 벌점을 최소화합니다.
   - 분리학생이 같은 반 / 동반학생이 다른 반 → 매우 큰 벌점 (사실상 금지)
   - 반별 인원, 남녀 수, 평균 성적, 성적 분포(표준편차), 특수·생활지도 학생 수, 1학년 같은 반 출신 쏠림 → 편차에 비례한 벌점
4. 화면의 **균형 중요도 슬라이더(0~5)**로 각 항목의 비중을 조절할 수 있습니다.

## 화면 기능
- 반별 현황표: 인원, 남/여, 평균, 표준편차, 특수, 생활지도, 1학년 반별 출신 수
- 조건 위반(분리·동반·고정) 자동 검사 및 빨간 테두리 표시
- 카드를 다른 반으로 끌어다 놓기 → **이동**, 다른 학생 위에 놓기 → **맞교환**
- 수동으로 옮긴 학생과 더블클릭한 학생은 🔒잠금 → `현재 배치 개선` 시 고정
- 새 번호 부여: 가나다순 / 남학생 먼저 / 여학생 먼저
- 결과 저장: `반편성결과`, `반별요약` 시트 생성 · `저장된 결과 불러오기`로 이어서 작업
- CSV 불러오기/내려받기, 인쇄, 이름·학번 검색, 성적 숨기기

> `Index.html` 파일만 브라우저로 열면 **데모 모드**로 동작합니다(예시 데이터·CSV 사용, 시트 저장 제외).
